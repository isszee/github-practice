# First To นักศึกษา — Character & Scene Prompt Collection

**Source:** `First To นักศึกษา - GitHub.pdf`  
**Collection type:** Character concept + visual scene studies  
**Public status:** Sanitized for a public repository

## Overview

This collection contains two visual directions from the source document:

1. **The Ice Queen** — a controlled, highly accomplished executive whose perfect life begins to reveal an unacknowledged emotional hunger.
2. **ENI visual studies** — a sequence of portrait, gallery, fashion, mirror, and intimate editorial scenes tracking a character through different emotional states.

The source also contains explicit adult material. That material is intentionally not reproduced here because this repository is public. The collection keeps the character design, cinematic direction, wardrobe language, and non-explicit scene structure.

## Suggested use

- Use the character file as a consistent identity anchor.
- Use the reusable-elements file to mix settings, wardrobe, and camera language.
- Use the final-prompts file as public-safe starting points for image generation.
