# UI Infographic Prompt Library

Public-safe draft extracted and reorganized from `UIinfographic.docx`.

> This draft contains reusable design systems, layouts, visual styles, and prompt-writing notes. Personal contact details, private project lore, and sensitive character-specific material have been intentionally omitted.

## Contents

- [UI infographic templates](./01-ui-infographic/)
- [Visual styles](./02-visual-styles/)
- [Design elements](./03-design-elements/)
- [Prompt workflow notes](./04-prompt-workflow/)

## Recommended workflow

1. Choose a layout.
2. Choose a visual style.
3. Fill the content cards.
4. Add only the effects needed by the style.
5. Copy the assembled prompt into the image model.
