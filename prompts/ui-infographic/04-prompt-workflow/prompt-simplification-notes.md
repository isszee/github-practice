# Prompt Simplification Notes

This document captures the lesson behind the revised daily infographic template.

## What improved

- Fewer variables to fill in.
- Real values in the working example.
- Two or three cards instead of an overloaded card grid.
- Four or fewer core effects.
- A final prompt that can be copied directly into an image model.

## Recommended assembly order

```text
[Format] + [overall style] + [background] + [title/text hierarchy] +
[layout] + [card content] + [palette] + [effects] + [lighting] + [legibility constraint]
```

## Before / after principle

The goal is not to remove creative detail. The goal is to move reusable detail into a modular system so the final prompt stays focused on the image being generated.

## Daily workflow

1. Pick one layout.
2. Pick one visual style.
3. Fill two or three content cards.
4. Select a limited effect set.
5. Generate.
6. Keep the successful version as a new example, not as a replacement for the reusable template.
